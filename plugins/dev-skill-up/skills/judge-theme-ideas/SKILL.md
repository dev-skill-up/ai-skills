# Judge Theme Ideas

## What a theme is

A theme idea has three parts: a **name**, a **description** of about five or six words, and a handful of **attributes**. Example: *City of Knowledge* / "knowledge is both currency and value" / you buy things by telling people what they don't know; lying is the worst offense; being wrong is like stinking in public; you can find out anything, for a price.

If the user's input doesn't arrive in this shape, normalize it first: extract the three parts from their prose and show the normalized form at the top of your judgment, so they can see exactly what you judged. If a part is missing outright (no description, a single attribute), report that at the gate and judge whatever is there.

## Why the judgment works this way

The short description is not a summary — it is the axiom the world runs on, and the attributes are its theorems. A theme gets used hundreds of times during worldbuilding: every institution, custom, scene, and rule gets derived from it. So the judge's job is to test whether the derivation chain actually holds: **name → description → attributes**. Judge structure only. Subject matter is out of scope — a theme about garbage collectors can be sound and a theme about elder gods can be broken, and dark, whimsical, or familiar material is neither a flaw nor a virtue here.

## The gate (cheap checks, first)

A name is present. The description is about five or six words (seven or eight deserves a note; a paragraph fails). There are at least two attributes. Run the gate and move on — a theme that passes it has proven nothing yet. Both worked examples below pass the gate; only one of them is sound.

## Test 1 — the swap test (name ↔ description)

Ask two questions: could this description sit under an unrelated name unchanged? Could this name take a stock description with nothing lost? Every content word of the name must be spent by the description. A flavorful word in the name that the description never touches is a **dead word** — the most common failure and the most expensive one, because the name is where the theme's raw material lives.

A related smell: a description that is pure temperament — trait adjectives about the members rather than a rule their world runs on. Traits describe; axioms produce, so temperament descriptions usually turn out inert. Confirm with Test 4 before condemning one, since a rule can wear trait-like clothing.

## Test 2 — the derivation test (description → each attribute)

For each attribute, write the derivation: *because [description], therefore [attribute]*. Judge two qualities: whether it is **tethered** (the *because* needs nothing beyond the description and name) and whether it **travels** (the *therefore* lands in a register the description never mentioned — economy, law, shame, ritual, childhood, architecture, death). Classify every attribute:

- **theorem** — tethered and travels. Surprising but derivable. The good kind.
- **paraphrase** — tethered but goes nowhere. Restates the description; padding.
- **smuggled** — travels but isn't tethered. Imported from outside the description. Check where it came from: smuggled material often turns out to be from the name's own semantic field, which means the description failed to claim what the name offered — the repair pointing at itself.
- **filler** — neither.

## Test 3 — coherence (attribute ↔ attribute)

A contradiction the axiom doesn't produce is a flaw: two attributes that can't both stand, with no mechanism connecting them. But tension the axiom *does* produce is a virtue, and you should name it as one. Worldbuilders need tension — it is where stories come from — and a judge that sands off axiom-produced tension makes themes worse. Calibration: "being wrong is disgusting even when it isn't your fault" is one principle producing both the innocence and the disgust. That's drama, not incoherence.

## Test 4 — generativity

Using only the name and description, derive two or three new attributes that are not on the user's list. If they arrive feeling inevitable, the theme is a machine; if only synonyms of the description arrive, it's a pile. This test also splits diagnoses: a generative description with weak attributes means *replace the attributes*; an inert description means no attribute list can save it — *rewrite the description*. Always include what you derived in the verdict. The yield doubles as a gift to the worldbuilder.

## Verdict format

Diagnose; don't grade. No scores, no ratings out of ten — even if the user asks you to "rate" it, a located diagnosis is the useful answer, because "your description never claimed salt" is actionable where "6/10" isn't. Use this shape:

**Verdict:** SOUND — or BROKEN at [the link(s) that failed]
**Gate:** only if something failed it
**Name ↔ description:** swap-test result; dead words named
**Attributes:** one line each — its classification, with the compressed because/therefore
**Coherence:** contradictions, or produced tension noted as a virtue
**Generativity yield:** the two or three new attributes you derived
**Minimal repair:** only if broken — the smallest change that fixes the deepest broken link

## Repair etiquette

Repair the deepest broken link first; downstream failures often heal on their own. The most common deep failure is a description that never claimed the name's semantic field, so the most common repair is: rewrite the description from the name's strongest associations, then re-derive the attributes, keeping any of the user's attributes that survive as theorems under the new description. Use material already latent in the name. Never replace the concept wholesale — the user came with salt fairies; give them better salt fairies, not obsidian monks.

## Judge discipline

- A sound theme gets a short verdict. Say SOUND, note the best attribute and why it's the model of the form, give the generativity yield, stop. Resist inventing flaws to look rigorous — false positives teach the user to ignore you.
- Don't demand more attributes; demand load-bearing ones. Three theorems beat seven paraphrases.
- Don't reward poetry that doesn't generate. A gorgeous description that yields nothing on Test 4 is inert, and saying so is the kindness.
- Several themes at once: judge each in full, then rank by generativity yield.

## Worked example — sound

**City of Knowledge.** Description: "knowledge is both currency and value" (6 words). Attributes: you buy things by telling people things they don't know; lying is the worst offense; being wrong is like stinking in public — maybe not your fault, still disgusting; you can find out anything, for a price.

Both content words are load-bearing: *currency* generates the market attributes (buying-by-telling; anything findable for a price), *value* generates the moral ones, and the best attribute needs both halves at once — false knowledge is counterfeiting and sacrilege simultaneously. "Being wrong is like stinking in public" is the model theorem: it travels to hygiene and no-fault shame, registers the description never mentioned, yet traces cleanly back. Generativity, on demand: misers who learn and never teach; inheritance is education; libraries are banks.

## Worked example — broken

**Salt Fairies.** Description: "they are straightforward and uncompromising" (5 words). Attributes: they give you things as they are; they value truth; their curses last a long time.

The gate passes, and everything after it breaks. The description fails the swap test — it fits iron fairies or granite dwarves unchanged — so "salt," the only flavorful word in the theme, is a dead word. "Give things as they are" and "value truth" are paraphrases: tethered, no travel. "Curses last a long time" is smuggled — the one genuinely salty attribute in the list (salt preserves; salted earth stays barren) and the description never licensed it. Note the diagnostic pattern: the smuggled attribute points at exactly what the repair should claim.

Minimal repair: description → "salt preserves, purifies, and pays" (5 words). Now attributes derive themselves: gifts that never spoil and curses that never fade (one power, both directions); they pay honest wages in salt that spends like silver; their blessings sterilize what they protect — the granary they guard never rots and never grows. "They value truth" survives as a theorem under *purifies*; the paraphrases retire.
